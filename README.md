# Reconhecimento da pergunta sim/não em Libras pela posição das sobrancelhas
Código do artigo "Reconhecimento de expressões faciais gramaticais da Libras a partir da posição das sobrancelhas: um experimento com classificadores simples"


## Como reproduzir
1. Abra `PesquisaAcademicaGrupoP.ipynb` no Google Colab.
2. Execute as células do início ao fim. O notebook baixa o conjunto de dados direto do UCI Machine Learning Repository, então não é preciso baixar nada antes.
3. Com a semente 42 e as mesmas versões das bibliotecas, os números do artigo se repetem.


## Versões usadas
Python 3.13.18, pandas 2.2.3, numpy 2.4.6 e scikit-learn 1.6.1


## Dados
Grammatical Facial Expressions (Freitas, Barbosa e Peres, 2014), UCI Machine Learning Repository, DOI 10.24432/C59S3R, licença CC BY 4.0.
Os dados não estão neste repositório.
